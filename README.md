## 実行環境

- PHP **8.5系**を対象としています。
- Day 2・3・7では `mbstring`、Day 4・6・7では `pdo_mysql` が必要です。
- データベースを使用するサンプルはMySQL 8系を想定しています。
- PHPのバージョンは `php -v`、有効な拡張は `php -m` で確認できます。
- Webサンプルはローカル開発環境で動かしてください。PHPの組み込みWebサーバーはインターネット公開用ではありません。

## 学習方法

1. 書籍のDayに対応するフォルダを開きます。
2. 各フォルダの `README.md` を読んで、実行環境と依存ファイルを準備します。
3. コードをコピーまたはダウンロードして実行します。
4. 書籍の実習・練習問題に取り組みます。

Day 7は `day07/task-app` に複数ファイルで構成されたWebアプリを収録しています。DB接続情報は環境変数で設定し、パスワードをソースに書き込まないでください。

## セキュリティと利用上の注意

本リポジトリのコードは学習目的です。公開サービスへ転用する場合は、認証・認可、HTTPS、入力検証、ログ管理、運用環境に応じたセキュリティ対策を別途設計してください。
